# Resultados dos Testes Estatísticos

Diretório criado automaticamente por `make bmm-package`.

Os resultados são gerados por `make test-nist-billion` (execução em servidor Linux
com NIST STS 2.1.2 e dieharder instalados) e copiados aqui antes da submissão à BMM.

Arquivos esperados após execução:
- `billion_YYYYMMDD_HHMMSS/binary_hash.txt` — SHA-256 do binário testado
- `billion_YYYYMMDD_HHMMSS/nist_final_report.txt` — Relatório NIST SP 800-22
- `billion_YYYYMMDD_HHMMSS/dieharder_results.txt` — Relatório Dieharder
